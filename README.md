# 📝 To-Do List – Java

A simple **To-Do List application built with Java** using `ArrayList`, `Scanner`, loops, methods, and `switch` statements.

## 🚀 Features

* ➕ Add a new task
* 👀 View all tasks
* ✏️ Edit an existing task
* 🗑️ Delete a task
* 🚪 Exit the application

## 🛠️ Technologies Used

* Java
* ArrayList
* Scanner
* Switch statement
* Do-while loop

## 📂 Project Structure

```text
To-Do-List/
│
├── Main.java
├── Task.java
└── README.md
```

## ▶️ How to Run

1. Clone the repository.
2. Open the project in your Java IDE.
3. Run `Main.java`.
4. Select an option from the menu.

## 📋 Menu

```text
<------------- Start To Do List ------------->

1. Add new Task.

3. Edit Task.
4. Delete your Task.
5. Exit
```
